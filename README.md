# comparison-artifact

The house style for single-page benchmark and comparison reports, published as Claude artifacts. It's React 18 and GSAP from cdnjs, with three React Bits components, all built into one self-contained HTML file.

`examples/bleep-timing/` is a complete worked report. It compares Parakeet, Qwen and hybrid word timings for Podly's profanity bleeps, scored against MFA. Copy it as the starting point for a new report.

## Use

```sh
mise install && mise exec -- npm install
mise exec -- node build.mjs examples/bleep-timing         # → examples/bleep-timing/index.html
mise exec -- node scripts/screenshot.mjs examples/bleep-timing   # → light.jpg (1280px), dark.jpg (400px)
```

The screenshot script prints horizontal overflow and console errors for both themes. Both should be `0` and `[]` before you publish.

For a new report:

1. `cp -r examples/bleep-timing examples/<name>`
2. Replace `data.json` with your results. Keep a top-level `"title"` (two to four words; it becomes the page `<title>`). The rest of the object is exposed to the app as `window.__BENCH__`.
3. Rewrite `app.jsx`: keep the shell (`useColorScheme`, `reducedMotion`, `Hero`, `App`'s section layout) and replace the sections.
4. Build, screenshot, then publish `examples/<name>/index.html` with the Artifact tool.

## What's shared

`template.html` holds everything that isn't report-specific:

- **Tokens.** Colors are custom properties on `:root`, redefined for dark mode both under `prefers-color-scheme` and under `[data-theme="dark"]`. Series colors are `--s-native`, `--s-qwen`, `--s-hybrid` and `--s-mfa`, with `--accent` for the series you're recommending. Rename them per report, but keep one accent.
- **Type.** Big Shoulders Display for headings and big figures, Atkinson Hyperlegible for body text, IBM Plex Mono for labels, axes and eyebrows.
- **Layout.**
  - `.hero` with a Waves background behind a left-fading gradient;
  - `.main`, a 1080px column;
  - `.section` and `.section__head`, an eyebrow, `h2` and lede;
  - `.chart-scroll`, a card that scrolls horizontally on phones instead of squashing a chart;
  - a 16px side gutter.
- **Component styles**, which work with any data:
  - `.findings` and `.finding`: stat cards wrapped in SpotlightCard;
  - `.lc-*`: an SVG line chart;
  - `.swears`: a heat-tinted table;
  - `.shows`: a comparison table with inline bars;
  - `.cost`: small multiples of horizontal bars, one card per metric;
  - `.mt-*`: a word timeline;
  - `.steps`: a numbered recommendation list;
  - `.method`: methodology fine print.

## Patterns in the example worth reusing

- **Motion.** Every animation goes through `useGSAP` with a `scope` ref. Scroll-triggered ones use `once: true`. Everything is skipped when `reducedMotion()` is true, so the static render is always the complete page.
  - SVG lines draw in with `strokeDashoffset`, then clear their dash props.
  - Bars grow with `scaleX` from `0 50%`.
- **Charts are hand-written SVG** with a fixed `viewBox` inside `.chart-scroll`. Labels go at line ends with leader lines, not in a legend. Dashed `.marker` lines show reference values ("your setting", "default").
- **The headline result goes in the hero.** The `.hero__facts` row holds three or four numbers.
- **Inline constants are fine** for small hand-curated data (a single passage, a resource table). Put anything generated by a script in `data.json`.

## Vendored React Bits

`vendor/react-bits/` holds SplitText, Waves and SpotlightCard (JS-CSS variants), fetched from the reactbits.dev registry. React Bits is MIT plus Commons Clause, by David Haz. `build.mjs` strips their ES imports and wraps each component in an IIFE that reads React, GSAP's SplitText and `useGSAP` from the UMD globals. The React Bits SplitText becomes `RBSplitText`, so it doesn't shadow GSAP's. To add a component, fetch it with the react-bits skill, then add it to `PRELUDES`, `EXPORTS` and the CSS list in `build.mjs`.

Script versions are pinned in `template.html`: React 18.3.1, GSAP 3.13.0 (with ScrollTrigger and SplitText) and `@gsap/react` 2.1.2. `@gsap/react` expects a lowercase `window.react`, which the template aliases.
